# Movie Hall Finder — UI/UX Revision V2.1
日期：2026-09-05  
定位：V2 精修版 / Mobile-first / 年輕化 / 10 秒決策型電影推薦 App

---

## 0. V2.1 核心原則

> **首頁只負責開始，搜尋結果才負責說服你。**

V2.1 不是更換產品方向，而是針對 V2 做進一步減法與資訊層級精修。

Movie Hall Finder 的首頁不應該同時展示推薦結果、Top Pick、PK、影廳規格、驗證狀態或其他功能。

首頁唯一任務是：

> **讓使用者快速開始搜尋。**

---

## 1. 為什麼要做 V2.1

目前 V2 已經比前版更年輕、更生活化，但首頁仍然承擔太多功能：

- 搜尋
- 偏好
- Top Pick
- 推薦理由
- 分數
- 影廳資訊
- 其他功能入口

這會讓首頁仍有「資訊展示頁 / Dashboard」感。

V2.1 要把首頁改成真正的「入口頁」。

### 核心 UX 判斷

使用者第一次打開 App 時，不應該先理解：
- 什麼是 Top Pick
- 什麼是影廳比較
- 什麼是驗證狀態
- 什麼是偏好權重

他只需要知道：

> 我想看什麼？  
> 我在哪裡？  
> 我什麼時候有空？  
> 幫我挑一場。

# 2. 首頁 Homepage — 只保留必要資訊

## 2.1 首頁必須保留

### Logo / App Name
Movie Hall Finder  
保持小而清楚，不搶視覺中心。

### 主標
**今晚想看什麼？**

### 副標
**我幫你挑最值得看的那一場。**

### 三個必要搜尋條件

1. 🎬 **電影**
   - Placeholder：`搜尋電影名稱`

2. 📍 **地點**
   - 預設：`桃園`
   - 可選：桃園 / 林口 / 附近

3. 🕒 **時間**
   - 現在
   - 今晚
   - 明天
   - 自訂

### 唯一主要 CTA
# **幫我挑一場 ✨**

---

## 2.2 首頁可保留的唯一輔助訊息

可在頁面底部放一行非常淡的小字：

> **資料不足時會告訴你，不亂猜。**

目的：
- 建立信任
- 呼應 Real Data Only
- 不干擾搜尋

---

# 3. 首頁禁止出現的內容

以下內容全部移到搜尋後：

- Top Pick
- 97 分
- 推薦理由
- 其他推薦場次
- 偏好加權
- Hall PK
- 影廳規格
- 帝王位
- 影城指南
- 幫我問影城
- Verified / Unknown / Mock 詳細狀態
- 資料來源
- 演算法說明
- Confidence
- 權重百分比

### 判斷標準

> 首頁不是產品展示頁。  
> 首頁不是 Dashboard。  
> 首頁不是規格頁。

# 4. 搜尋後 Results Page

搜尋後才正式進入「電影決策模式」。

## 4.1 頁面資訊順序

1. Top Pick
2. 為什麼推薦
3. 其他 2～3 個替代場次
4. 想更合你胃口？
5. 兩場直接 PK
6. 影廳詳情
7. 去這間影城
8. 幫我問影城
9. 資料來源 / 更新時間

---

# 5. Top Pick 搜尋結果英雄卡

## 第一眼要看到

- 電影海報
- 電影名稱
- 時間
- 影城
- 影廳
- 推薦理由
- 分數（次要）

### 範例

**🏆 今天最值得看**

《希望：末日血戰》

**15:40 · 桃園統領威秀 · 1廳**

**97 分**

超大廳 · Atmos · 時間剛好 · 距離近

主要 CTA：
**就看這場**

次要：
- 看其他推薦
- 跟別場 PK

# 6. 偏好設定 V2.1

首頁不顯示偏好。

搜尋後才顯示：

## **想更合你胃口？**

選項：
- 🏟️ 我就是要大廳
- 🔊 音效畫質優先
- 🕒 時間最重要
- 💰 便宜最重要
- 🚗 不要跑太遠

可使用：
`不在意 / 有點重要 / 很重要`

不要顯示百分比與演算法數值。

---

# 7. Hall PK V2.1

搜尋後才能進入。

先顯示結論，不先顯示完整規格。

### 範例

# **兩場直接 PK**

🏆 **綜合推薦：A 場**

- 🏟️ 大廳：A 勝
- 🔊 音效：B 勝
- 🚗 交通：A 勝
- 💰 價格：B 勝
- 🕒 時間：A 勝

一句人話：

> **想看得爽選 A；想省錢選 B。**

完整規格放第二層。

---

# 8. 影廳詳情 V2.1

標題用人話：

# **桃園站前的大型主力廳**

摘要：

> 適合動作片、科幻片與大片。

資訊順序：

1. 影廳大小感
2. 特殊格式
3. 帝王位
4. 螢幕 / 音效
5. 詳細規格
6. 資料來源

---

# 9. 影城出遊指南 V2.1

只保留三大區：

## 🚗 怎麼去
## 🅿️ 停哪裡
## 🍜 看完吃什麼

不要再做成大量資訊卡。

---

# 10. 幫我問影城

前端只使用：

# **幫我問影城 📞**

不要顯示：
- AI Voice Agent
- Realtime API
- MissingInfoTask
- Calling Agent

狀態文字：

- 正在幫你確認
- 已確認
- 影城暫時沒有回答
- 稍後再試

# 11. V2.1 配色系統

## 整體氣質

> **深夜電影感，不是電競感；年輕，但不是霓虹科技感。**

## 主背景

避免純黑。

建議：
- `#111214`
- `#15161A`

## 主文字

- `#F5F5F7`

## 次文字

- `#9A9CA2`

## 主 Accent

電影琥珀橘：

- `#FF9F1C`

僅使用在：
- 「幫我挑一場」
- Top Pick
- 勝負結果
- 極少數重要狀態

### 比例原則

> **80% 深色背景 + 15% 白灰文字 + 5% Accent**

不要整頁橘。

---

## 11.1 資料狀態色

### Verified
小面積綠色

用途：
- 資料已確認

### Unknown
柔和黃

用途：
- 尚未確認
- 資料不足

### Mock / Demo
紫灰 / 藍灰

用途：
- Demo
- Mock

Mock 不可使用跟 Verified 相同的色彩。

---

# 12. 視覺風格

關鍵字：

- 深夜電影感
- 年輕
- 手機優先
- 大圖
- 少字
- 留白
- 高對比
- 內容感
- 不像後台
- 不像金融 App
- 不像電競 App

可參考的「感覺」：
- Netflix 的內容感
- Letterboxd 的電影氣質
- Apple Music 的簡潔層級

不是照抄 UI，而是參考資訊密度與內容優先順序。

---

# 13. Mobile Interaction Rules

1. 首頁不需要往下滑才能開始搜尋。
2. 主要 CTA 在拇指容易點的位置。
3. 搜尋後才載入決策資訊。
4. Filter 使用 Bottom Sheet。
5. 詳細資訊 progressive disclosure。
6. 不在手機主流程放橫向大表格。
7. 返回首頁時保留上一組搜尋條件。
8. 搜尋完成後 Top Pick 儘快出現在首屏。
9. 主要流程最多 1 個主 CTA。
10. 首頁動畫要輕，不要做霓虹或電競效果。

---

# 14. Real Data Only 規則

核心原則：

> **資料可以少，但不能假。**

狀態：

- ✅ 已確認
- 🟡 尚未確認
- ⚪ 未知
- 🧪 Demo / Mock

### 首頁

不顯示複雜驗證狀態。

### 搜尋結果

必要時只顯示：

- 資料已確認
- 部分資料尚未確認

### 詳細層

再提供：
- 資料來源
- 更新時間
- Confidence
- 驗證方式

Unknown 必須允許存在。

# 16. V2.1 Acceptance Criteria

## Homepage

- [ ] 首頁只保留電影 / 地點 / 時間
- [ ] 有清楚「幫我挑一場」
- [ ] 首頁不出現 Top Pick
- [ ] 首頁不出現 97 分
- [ ] 首頁不出現 Hall PK
- [ ] 首頁不出現影廳規格
- [ ] 首頁不出現資料分析細節
- [ ] 390px 手機寬度正常
- [ ] 一打開就知道怎麼開始

## Search Results

- [ ] 搜尋後才顯示 Top Pick
- [ ] Top Pick 在結果頁首屏可見
- [ ] 第一眼看得到電影 / 時間 / 影城 / 影廳
- [ ] 推薦原因 3 秒內理解
- [ ] 分數不是主視覺

## Visual

- [ ] 深色背景不是純黑
- [ ] Accent 使用比例受控
- [ ] 不像工程 Dashboard
- [ ] 不像電競 UI
- [ ] 不像金融評分 App
- [ ] 電影海報與內容成為視覺主角

## Data

- [ ] Mock 明確標記
- [ ] Unknown 可以存在
- [ ] Verified 可追來源
- [ ] 不因 UI 需求虛構資料
