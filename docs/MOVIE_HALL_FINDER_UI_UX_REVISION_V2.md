# Movie Hall Finder — UI/UX Revision V2
日期：2026-09-05  
定位：Mobile-first / 年輕人快速決策 / 10 秒內選出最值得看的場次

## 0. 一句話核心

> **不用自己查半天，我幫你挑今天最值得看的那一場。**

Movie Hall Finder 不是影廳資料庫，也不是電影規格研究工具。  
它的核心任務是：**讓使用者在 10 秒內做出「去哪裡看、看哪一場」的決定。**

---

## 1. V2 最高優先目標

### P0 — 必改
1. 首頁資訊量砍半，只保留「電影 / 地點 / 時間 / 幫我挑一場」。
2. Top Pick 必須成為畫面絕對主角。
3. 結果先講「去哪一場」，再講「為什麼」。
4. 專業資料、演算法權重、來源與驗證資訊降到第二層。
5. 手機版所有主要操作都能單手完成。
6. 禁止把 App 做成 Dashboard / 後台 / 規格表。

### P1 — 強烈建議
1. 電影海報與影廳照片的視覺比重提高。
2. VS 比較改成「誰贏什麼」而不是規格矩陣。
3. 影廳詳情使用生活化說法。
4. 影城指南只保留「怎麼去 / 停哪裡 / 看完吃什麼」。
5. 所有技術詞改成人話。

---

## 2. 目前版本的主要問題

### 2.1 首頁太像資訊 Dashboard
目前 Logo、資料原則、搜尋、偏好、Top Pick、分數、資料狀態、VS 等同時搶注意力。

**V2：首頁只回答一件事：今天哪一場最值得看？**

### 2.2 97 分太像系統分數，不像推薦
分數可以保留，但不應該比「電影、時間、影城、影廳」更醒目。

### 2.3 黃橘色使用過量
當所有東西都是高亮，就沒有真正的重點。

### 2.4 「偏好加權」太工程
使用者不需要理解「演算法權重」。  
他只需要選：
- 我想看大廳
- 我想要特殊音效
- 我不要跑太遠
- 我想省錢

### 2.5 VS 比較太像規格表
應改成一眼知道：
- 大廳：A 勝
- 音效：B 勝
- 交通：A 勝
- 價格：B 勝
- 綜合：A 勝

## 3. V2 首頁重新設計

### 3.1 首屏 Hero

標題：
**今晚想看什麼？**

副標：
**我幫你挑最值得看的那一場。**

搜尋區只保留三個條件：

1. 🎬 電影  
   Placeholder：`搜尋電影名稱`

2. 📍 地點  
   預設：`桃園`
   可切換：桃園 / 林口 / 附近

3. 🕒 時間  
   快捷選項：
   - 現在
   - 今晚
   - 明天
   - 自訂

主 CTA：
## **幫我挑一場 ✨**

不要使用「搜尋」、「查詢」、「開始分析」。

---

## 4. Top Pick 英雄卡

### 卡片優先順序
1. 電影海報
2. 電影名稱
3. 時間
4. 影城 + 影廳
5. 一句推薦理由
6. 分數
7. 次要細節

### 範例

**🏆 今天最值得看**

《希望：末日血戰》

**15:40 · 桃園統領威秀 · 1廳**

**97 分**

超大廳 · Atmos · 時間剛好 · 距離近

CTA：
- **就看這場**
- 看其他推薦
- 跟別場 PK

### 重要
97 分是「輔助」，不是主角。  
不要讓畫面看起來像股票評分或性能 Benchmark。

---

## 5. 推薦理由改成「人話」

禁止：
- 權重 30%
- Hall Score 92
- Confidence 0.87
- 距離係數
- 格式加權

改成：
- **這間廳夠大**
- **動作片看起來更爽**
- **時間最順**
- **不用跑太遠**
- **今天價格比較划算**
- **資料已確認**

若需要顯示細節，放在「為什麼推薦？」展開區。

---

## 6. 偏好設定 Bottom Drawer

入口名稱：
**想更合你胃口？**

選項改成生活語言：

- 🏟️ **我就是要大廳**
- 🔊 **音效畫質優先**
- 🕒 **時間最重要**
- 💰 **便宜最重要**
- 🚗 **不要跑太遠**

每項可用簡單三段式：
`不在意 / 有點重要 / 很重要`

不要出現百分比、slider 數字、權重總和。

---

## 7. 推薦清單

Top Pick 下方只顯示 2～3 個替代場次。

卡片格式：

**#2 比較近**
18:20 · 林口 XXX · 8廳  
89 分  
「少跑 15 分鐘，但影廳較小」

**#3 比較省**
20:10 · 桃園 XXX · 6廳  
85 分  
「便宜 NT$80，但沒有 Atmos」

目的：讓使用者理解「為什麼不是第一」。

---

## 8. Hall VS 重做

標題：
# **兩場直接 PK**

不要一開始出規格矩陣。

先顯示結論：

| 項目 | 勝者 |
|---|---|
| 🏟️ 大廳 | A |
| 🔊 音效 | B |
| 🚗 交通 | A |
| 💰 價格 | B |
| 🕒 時間 | A |

最上方：
**🏆 綜合推薦：A 場**

一句話：
**如果你在意整體爽度，選 A；想省錢，選 B。**

再提供「看完整規格」作為第二層。

---

## 9. 影廳詳情

標題不要只有：
`Hall 1 / 284 seats`

改成：
# **桃園站前的大型主力廳**

摘要：
**適合動作片、科幻片與大片。**

資訊排序：
1. 大小感
2. 特殊格式
3. 建議座位
4. 螢幕/音效
5. 詳細規格
6. 資料來源

### 帝王位
用一句話：
**推薦：中間偏後 2～3 排。**

若無可靠座位資料：
**最佳座位目前未確認。**

---

## 10. 影城出遊指南

頁面只做三大區：

### 🚗 怎麼去
- 開車時間
- 大眾運輸
- 距離

### 🅿️ 停哪裡
- 停車場
- 電影折抵
- 是否容易滿

### 🍜 看完吃什麼
- 商場餐廳
- 附近宵夜
- 營業時間

不要做成大量資料卡。

---

## 11. AI Voice Agent 前端命名

禁止直接寫：
- AI Voice Agent
- Realtime API
- Calling Agent
- MissingInfoTask

使用者看到的是：

# **幫我問影城 📞**

提示：
**這個影廳資料還沒確認，要不要幫你問？**

狀態：
- 正在確認
- 已確認
- 影城暫時沒回答
- 稍後再試

技術細節完全隱藏。

---

## 12. 資料真實性規則（不可犧牲）

Movie Hall Finder 核心原則：

> **資料可以少，但不能假。**

每筆資料必須有狀態：

- ✅ **已確認**
- 🟡 **尚未確認**
- ⚪ **未知**
- 🧪 **Demo / Mock**

### 視覺規則
不要讓「Verified / Confidence / Source」霸佔首頁。

首頁只在必要時用小型文字：
**資料已確認**

詳細來源放到展開區：
`資料來源與更新時間`

若資料不完整：
**部分影廳資訊尚未確認，推薦結果可能調整。**

---

## 13. 視覺風格 V2

### 關鍵字
- Netflix / Letterboxd / Apple Music 的內容感
- 電影感
- 年輕
- 深色
- 留白
- 大圖
- 少文字
- 高對比
- 不像工程後台

### 色彩
深色背景保留。

Accent color 只用在：
- CTA
- Top Pick
- 勝負結果
- 少量狀態

不要整頁黃橘。

### 卡片
- 大圓角
- 少框線
- 用背景層次代替大量 border
- 海報與圖片優先
- 每張卡最多 1 個主 CTA

---

## 14. 手機互動規則

1. 主要 CTA 要在拇指容易點的位置。
2. Filter 使用 Bottom Sheet。
3. Modal 不要塞滿整頁資料。
4. 詳細資訊用 progressive disclosure。
5. 卡片之間可以滑動。
6. 所有主要流程不得要求橫向閱讀表格。
7. 首頁載入後 10 秒內可完成第一次決策。
8. 返回時保留搜尋條件。

## 16. V2 Acceptance Criteria

### 首頁
- [ ] 首屏不超過 3 個主要輸入
- [ ] 有明確「幫我挑一場」CTA
- [ ] 不顯示工程/資料技術術語
- [ ] 手機 390px 不需要縮放

### Top Pick
- [ ] 海報 / 電影 / 時間 / 影城優先於分數
- [ ] 3 秒內理解推薦原因
- [ ] 主 CTA 明確
- [ ] 可查看其他推薦

### Hall PK
- [ ] 先顯示勝負，再顯示規格
- [ ] 5 秒內知道兩場差別
- [ ] 不需左右拖動表格

### Hall Detail
- [ ] 先講「這間廳好不好」
- [ ] 再講規格
- [ ] Unknown 不補假資料

### Data Integrity
- [ ] Mock 必須標記
- [ ] Unknown 可以存在
- [ ] Verified 必須可追來源
- [ ] 不因 UI 好看而虛構資料

## 17. 給前端 AI 的實作指令

### 核心要求

請將目前 Movie Hall Finder UI 重構為 **Mobile-first、10 秒決策型產品**。

不要新增更多功能，優先做資訊減法。

使用者的第一任務是：
> 輸入電影、地點、時間 → 立即看到最值得看的場次。

### 必做
1. 重做手機首頁。
2. Top Pick 改成電影內容型 Hero Card。
3. 隱藏演算法/資料工程細節。
4. 偏好改成生活化 Bottom Drawer。
5. Hall PK 先顯示勝負。
6. Hall Detail 先寫人話。
7. Theater Guide 簡化成交通 / 停車 / 美食。
8. AI Voice Agent 改名「幫我問影城」。
9. 保留 Real Data Only / Unknown Allowed。
10. 桌機版從手機版自然延伸，不另外做 Dashboard。

### 不要做
- 不要增加更多 KPI
- 不要增加更多圖表
- 不要增加更多 Badge
- 不要增加資訊密度
- 不要做成電影資料庫
- 不要做成工程分析工具
